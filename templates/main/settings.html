  1. Go to Google Cloud Console
  2. Create a new OAuth 2.0 Client ID
  3. Set authorized redirect URIs to: https://yourapp.com/auth/google/callback
  4. Copy the Client ID and Client Secret and paste them above

  1. Go to GitHub Developer Settings
  2. Create a new OAuth App
  3. Set callback URL to: https://yourapp.com/auth/github/callback
  4. Copy the Client ID and generate a Client Secret

  1. Go to Azure Portal
  2. Register a new application
  3. Add redirect URI: https://yourapp.com/auth/outlook/callback
  4. Create a client secret in "Certificates & secrets"
  5. Copy the Application (client) ID and the client secret value
